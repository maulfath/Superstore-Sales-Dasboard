## 📝 Project Overview
This project is a fully interactive, pixel-perfect Excel dashboard designed to analyze and visualize the sales performance of a retail superstore. This dashboard was developed as a capstone project during my independent study program at **Vinix**, aimed at demonstrating end-to-end data processing, business intelligence reporting, and macro automation.

The dashboard allows stakeholders to dynamically drill down into historical sales data across various dimensions such as time, geography, product categories, and customer segments to uncover actionable business insights.

## 🛠️ Tools & Technologies Used
* **Microsoft Excel** (Data Cleaning, Pivot Tables, Pivot Charts)
* **Visual Basic for Applications (VBA)** (Macro Automation)
* **UI/UX Design** (Shape formatting, interactive UI, layout optimization)

## 🎯 Key Performance Indicators (KPIs)
The dashboard features four primary metrics at the top to give executives a quick snapshot of the business's health:
1. **Total Sales:** Overall revenue generated.
2. **Total Orders:** The volume of transactions.
3. **Average Sales:** Average revenue per transaction.
4. **Max Sales (Top Deal):** The single highest transaction value recorded, indicating peak customer purchasing power.

## 📈 Visualizations & Features
* **Interactive Slicers:** Multi-dimensional filtering by **Months**, **Years**, **Region**, **Category**, and **Segment**. 
* **Dynamic Reset Button (VBA):** A custom-built macro button ("Reset Filters") that clears all active Slicer caches instantly, providing a seamless user experience.
* **Top 5 State Performance:** A filtered bar chart highlighting only the top 5 states by sales to avoid visual clutter and focus on major revenue contributors.
* **Trend & Composition Analysis:** 
  * *Monthly Sales Trend* (Line Chart) to track seasonality.
  * *Sales by Segment* (Donut Chart) to view customer demographics.
  * *Sales by Category & Sub-Category* (Bar Charts) to identify best-selling product lines.
  * *Top 5 Customers* to identify high-value clients.

## 💻 How to Use This Dashboard
### Opsi 1: Coba Langsung di Web Browser (Excel Online)
Klik tautan interaktif berikut: **[Live Excel Online Demo](https://1drv.ms/x/c/f75bc79e201ded9e/IQBjJvDwUsPNTaWWrIdQCnwxAfGIKIeIkVzsiPLwlZWEzdQ?e=zKg4ZH)** untuk mencoba seluruh slicer filter secara langsung.

### Opsi 2: Download & Buka di Microsoft Excel Desktop
1. Download file `Superstore_Sales_Dashboard.xlsm` dari repository ini.
2. Buka file di Microsoft Excel desktop.
3. **Penting:** Klik **"Enable Editing"** dan **"Enable Content"** (Macros) pada bar kuning notifikasi keamanan di bagian atas agar tombol *Reset Filters* (VBA) berfungsi optimal.
4. Gunakan panel Slicer di sebelah kiri untuk eksplorasi data.
